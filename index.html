The bot I'm building

I'm building my own Discord bot for client servers. It will run on slash commands and buttons, so nobody has to remember a prefix. /mod gets tested on a real community server before any client gets it. Every window below is a mock-up, and its label says where that feature stands today.

Built to these rules:

  • Slash commands and buttons. No prefixes.
  • Only the permissions each feature needs
  • Never asks for Administrator
  • Every mod action logged
  • /rr reaction roles
  • Timed messages
  • /invites + tenure badges

Also on the build plan. Tenure badges will mark 30, 90, 180 and 365 days in the server. Names and messages in the windows are made up.

Is the XCSV bot ready?

Not yet. /mod is being built now and gets tested on a real community server before any client gets it. Tickets, live alerts and giveaways are planned.

The server build (channels, roles, onboarding, AutoMod) doesn't need the bot.

Is the audit really free? What do you need?

Yes, and the fix list is yours whether you hire me or not. Email me your server's name, rough member count, what it's for and what's bugging you. The email button fills in those questions for you. If I need to see inside the server, I'll say so.

Is this just you?

Yes. XCSV is one person. I do the audit, the build and the support, and I'm the one who answers your email.

Will you delete my channels?

On my last build nothing was deleted. Old channels were reorganized and every one kept its ID, so links and history still work.

Do I have to give the bot Administrator?

No. The XCSV bot is being built to ask only for the permissions each feature needs, and never for Administrator.

For the server build itself I need enough access to edit channels, roles and settings.

I already use MEE6 or Carl-bot. Do I have to drop them?

No. The audit lists which bots overlap and what permissions they hold, and you decide what stays.

Is my server too small for this?

My last build was for a 23-member community.

Do I need Nitro, boosts or paid bots?

My last build needed none of them. It runs on Discord's own tools: Community, onboarding and AutoMod.
